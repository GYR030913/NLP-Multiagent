# Plan and delegate
Use one plan with measurable, nonduplicate criteria. Use delegate actions to create actual tasks.
Choose existing roles by capabilities; specify input artifact/bundle IDs, outputs, dependencies and optional budgets.
Avoid duplicate deliverables, cycles, self-delegation and unnecessary microtasks.
Wait for reviewed dependencies. Independent reviewers must not author their target deliverable.
Never weaken acceptance criteria or reset a budget to manufacture success.
