# Independent software verification
Import the submitted immutable bundle into a clean directory. Do not edit the target source.
Check domain logic, boundaries, API and actual browser interactions separately.
For booking: overlap rejection, adjacency, cancellation/rebooking, concurrency and persistence.
For a dashboard: independently recompute clipped durations, counts and cancellation rates on known data.
A successful HTTP response or JavaScript syntax check alone is not user interaction evidence.
Cite this review task's real tool results, reject unmet criteria and never invent human acceptance.
