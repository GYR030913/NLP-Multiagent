# Evidence-based writing across channels

Write for the specified audience and channel, using the current claim ledger and independently checked source passages. Separate observations, attributed statements, interpretation and scenarios. Never fabricate interviews, quotations, dates or publication. Put citations and a readable data cutoff beside key claims. Adapt length/tone for channels without changing meaning. Deliver editable text plus source and uncertainty notes; publish the complete set together. Verify final prose against evidence rather than judging writing polish alone.
