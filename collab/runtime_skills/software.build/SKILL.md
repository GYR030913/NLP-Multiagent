# Build software
Read agreed requirements and prior delivery contracts. Implement in small, executable increments.
Preserve cancellation history, timestamps and data compatibility. Document interval and timezone semantics.
Run meaningful tests, including concurrency and restart persistence; zero discovered tests is not success.
Publish all required source, tests and instructions as a bundle. ZIP is not a supported source artifact.
When fixing a defect prefer a short exact replacement to rewriting the full application.
