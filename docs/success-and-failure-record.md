## 已落实的失败改进

### 上下文与短期记忆

- 目标、验收条件只放一份，持久化工作集保留原文；旧产物、历史来源和维护说明通过引用保留。
- 当前任务最新工具结果优先，随后发生的上下文错误不挤掉它；尚未解决的最新错误另行显示。
- 阅读台账保留文件范围、符号、来源区间和精确引文事件，检验台账保留执行结果，减少跨页面遗忘。
- 最近三条不同的观察、工具计数、距最近写出成果的调用次数形成 progress 摘要。连续八次读取没有写出成果时，提示小步实现或有依据的草稿；这是建议，不会自动放宽验收或强迫伪造结论。
- 限制重复计划和命令预览，避免递归压缩导致体积膨胀。

### 研究工具

- 工具描述明确 topic=general/news/finance、time_range=day/week/month/year；历史研究省略 time_range，减少未知枚举错误。
- 默认只展示本轮来源和论断。历史来源保留 ID，论断通过 include_history=true 明确调取；可读历史不等于本题已经重读核实。
- 同一任务、同一 PDF 快照、相同正文与页码映射复用来源 ID。解析仍真实执行；不同任务不复用此身份来代替独立核查，来源 ID 增长不再冒充新进展。
- HTTP 403、正文超限、PDF 无文字仍按失败/局限报告，不把搜索片段冒充原文。

### 运行和评估

只使用现有执行控制器；维护不退还动作预算，失败不改为通过。新软件重试明确标注 retry_of=r2。代码变化归档为不同 implementation epoch。自动测试通过与真实人工验收分开，恢复诊断不自动批准交付。
