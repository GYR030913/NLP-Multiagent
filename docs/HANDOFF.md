## 已发现并修复的问题

1. 接口地址必须包含 /v1，否则当前服务返回 404。
2. Docker 引擎须先启动，否则代码执行无法连接沙箱。
3. tests/__init__.py 最初未发布，导致干净副本发现 0 个测试；QA 退回后补齐并复验。
4. 非 raw 的 Python HTML 字符串吞掉 JavaScript 转义，造成页面显示但按钮失效。v1.0.1 使用 raw 字符串修复。
5. 模型曾错误断言“语法检查对新旧版本都通过”。实际对照确认旧版 a2 检查失败、新版 a8 通过；发布说明已重新发布为 a10。不要复用这个早期错误经验。
6. 平台补充了静态 JS 检查、精确替换、总请求超时、截断短动作恢复、文件锁、中断恢复及近期动作/证据上下文。

静态检查、HTTP/API 测试与真人浏览器点击是不同证据，应分别报告。当前测试与进度文档中若有较早阶段的表述，以本检查点和实际运行记录为准。

## GitHub 包含和不包含什么

仓库包含平台源码、测试、原始场景、配置模板和文档。

不包含 .env、runtime/、真实预约数据库、原始完整对话和各角色的本地记忆。原电脑这些文件仍保留，新队友克隆后不会自动拥有原运行会话。

预约系统的正式生成产物和数据库目前主要在原电脑 runtime/software/ 下。fixes/booking-ui/ 是修复诊断候选，不是完整可运行的预约系统发布包。不要把它当成已经发布的独立示例；后续可从正式导出中另存不含个人数据的完整示例。

## 队友从零运行

安装 Python 3.11+、Node.js 和 Docker Desktop。复制 .env.example 为 .env，在本地配置课程允许的密钥。

在正常 Python 环境执行：

```powershell
docker build -f Dockerfile.sandbox -t campus-collab-sandbox:local .
python scripts/run_checks.py
python scripts/probe_api.py
python scripts/check_runtime.py --search
python scripts/prepare_groups.py
python -m collab chat software
```

原电脑默认 python 指向无法正常启动的 peft312 环境，应使用：

```powershell
& 'D:\Anaconda\python.exe' -m collab chat software
```

队友使用自己的正常 Python 路径，不必照搬原电脑的盘符。
