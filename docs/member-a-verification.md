## HKGAI 问题定位与修复

此前最小请求也长时间无输出。本轮对照结果：

- Windows Python 3.10 + OpenSSL 1.1.1向同一端点发送最小请求成功。
- Windows Python 3.11 + OpenSSL 3.5在TLS握手阶段重复超时。
- 同一电脑的Windows curl使用Schannel可以正常完成握手并访问API。
- `LLM_TRANSPORT=auto`现在在Windows Python 3.11+优先使用curl。

curl认证值只通过子进程环境传递，不出现在命令行参数、日志或异常消息中。新增测试验证HTTP错误不会被误报为成功，凭据不会进入argv。

## 本轮修复

- 审查证据必须属于当前审查任务和当前审查者，不能复用旧审查证据。
- 审查节点也占用任务预算，创建节点前统一检查上限。
- 模型动作预算按运行持久化，恢复不会重置。
- 根任务必须先提交非空、不重复的验收条件。
- B、C、D增加最小结构契约，现有工具、记忆和人类交互实现通过兼容性测试。
- Windows Python 3.11的HKGAI传输增加curl回退。

这些修复已由新增回归测试覆盖；它们不代替真人验收。
