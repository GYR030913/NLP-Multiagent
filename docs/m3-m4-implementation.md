# M3 / M4 实施与验证记录

本轮在 `codex/m0-m2-harness` 的未提交工作基础上增量实现。用户已确认预约系统，并授权继续 M3、M4 以及三个场景、六项连续任务的自主测试。原始角色与题目没有改写。

## M3：工作集与长期记忆

详细逻辑、状态、隐私边界、恢复顺序和管理命令见 [记忆管理逻辑](memory-management.md)。

新增 `collab/memory.py` 和 `collab/working_set.py`，接入 Store、Engine、上下文、工具网关和导出。主要能力包括：

- 有来源的 per-task 工作集，持久化原样人工约束、验收版本、输入与依赖、假设和未解决问题。
- 上下文预算、原始事件/正文分页、每次调用的压缩与检索轨迹。工具描述只传一次。
- 类型、作用域、证据、TTL、内容版本、候选/验证/争议/过期/撤回/替代状态。
- propose/search/inspect/challenge/share，权限过滤早于关键词评分；私信来源不能仅靠 owner 相同进入公共任务。
- state outbox、稳定 operation_id、追加日志和可重建 SQLite 索引；旧 JSONL 只导入为未验证状态。
- 规则触发的有限失败反思、候选经验、明确的人工提升管理与隐私清除。

当前检索是可解释的确定性关键词策略，不依赖 FTS5 或向量服务。没有自动提升 prompt/skill，M6 的受控演进仍未实施。

## M4：来源、论断、文档与数据

新增 `collab/research.py`、`collab/documents.py`、`collab/document_worker.py`、`collab/public_http.py` 和 `collab/data.py`。

来源工具区分搜索线索和已取得正文。正文按哈希保存，记录检索日期、可获取的发布日期和原始来源属性；未知日期保持未知。`evidence.read_source` / `find_quote` 提供精确字符偏移和 PDF 页码，`record_claim` 保存支持、反对、不确定关系与局限。台账校验出处，不自动证明论断为真。

公开下载逐跳检查 HTTPS 公网地址，连接绑定已验证 IP，限制正文/PDF 大小；证书链兼容路径也保留 TLS 验证和地址检查。私网跳转、伪装 PDF、过大响应和不受支持格式被拒绝。

PDF 在独立离线镜像解析，固定 `pypdf==6.1.3`，最多 20 MB、100 页、有限提取字符和容器时间/内存。无文字材料报告 `no_text`，损坏件报告失败；没有宿主解析或 OCR 降级后冒充全文核实。

`data.register` 接受 CSV/JSON，以及已经由操作员授权的只读预约 SQLite 快照；保留原文件/标准化数据哈希、schema、时区、币种、日期、provenance 和版本。默认移除 booker/title/email/phone 等字段。模型自己写的 SQLite manifest 不能代替操作员存档授权。

`data.analyze` 只支持有限操作，不开放任意 SQL 或 eval：

- 预约窗口交集、取消率、按房间/日期/小时汇总，含跨日、相邻和无数据处理。
- Decimal 权重、HKD/USD、费用、现金和明确假设的压力场景。
- 显式列的分组求和。
- 检测器基准发生率示例的 PPV 复算。

复杂分析通过 `data.export` 输出脱敏快照，再在 Docker 中编写代码。没有数据时不凭空输出精确相关系数，也没有真实交易或外部发布接口。

补齐六个运行时 skills：可溯源研究、独立核查、证据写作、模拟组合、行业研究和离线 HTML 演示。它们保留独立版本和正文摘要，不替代原始角色或预写题目答案。

修复后使用新的独立目录 `runtime/selftest_m3_m4_20261121_v2`，固定并归档代码、模型配置、skills、镜像及每群组空初始记忆。三个场景分别建立原始四角色群组；每个场景先执行 Task 1，再在同群组继续 Task 2。

每个交付仍需独立角色审查。之后操作员对具体版本检查文件、来源、数据或真实浏览器结果，并把证据与产物哈希绑定。自动通过使用 `test_passed`，仅在自测群组解锁下一题；它不生成 `human_answer`，不计为正式人工验收。
