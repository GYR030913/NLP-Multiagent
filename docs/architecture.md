# 系统架构与设计边界

## 路由与调度

CLI → Engine → 单个角色的 JSON 动作 → Tools → 结构化结果 → 持久化事件 → 下一轮。

一个群组加载四个原始角色提示词。模型自主选择协商、拆分、委派、澄清、工具、提交；编排器验证动作和权限并以队列调度。没有固定“研究→开发→审查”流水线，也没有为测试题写死最终答案。默认顺序调度使事件和共享文件快照可复核；它不是并行性能优化实现。

工作任务包含所属智能体、验收条件、依赖子任务、父任务、重试次数和状态。根任务必须先计划；委派深度最多5，每轮目标最多40个节点，审查节点同样占预算。一次调度最多120个模型动作，整个运行另有360个动作的持久化硬预算，恢复不会重置。审查最多允许3次返工；达到上限标记失败。一个角色可以给其他角色委派，自己不能审查自己的产物。审查节点不继续委派，避免审查递归。

同一任务只允许一次计划，避免反复改写计划却不执行。委派可声明现有任务 ID 的 `depends_on`，依赖完成后自动唤醒；系统同时检查父子完成关系与显式依赖，拒绝循环。达到返工上限时整次目标记为失败，结束该目标的未完成节点，而不是无限等待。人类也可通过 `/abort 原因` 终止试跑并保留失败记录。

工作状态：running → waiting_for_children / waiting_for_human / reviewing → completed / failed。子任务提交自动创建独立审查任务。审查通过后父任务得到可追溯结果；拒绝后原负责人收到反馈并返工。根任务审查通过仍需人类最终验收。

`plan`提出非空、不重复且可核查的标准。审查必须覆盖任务标准，证据引用当前审查任务中由当前审查员获取的`tool_result`，不能引用其他任务或历史审查的旧证据，也不能把执行失败作为通过证据。框架只能检查证据来源及执行状态，无法静态保证审查员的语义判断正确；人类或课程评测仍需核验真实产物。

## 人类交互

澄清、删除、GitHub 推送、最终验收都写为持久化请求。M1 的 `/resume` 分批与连续模式在存在待处理人工请求时统一交回控制权，即使其他任务已就绪也不自动继续；处理请求后再次恢复。回答按请求 ID 关联，审批必须显式 approve/reject，不能用普通字符串“yes”代替布尔审批；澄清必须提供实际文字回答。拒绝最终交付会重新打开任务。

私信只进入对应私有任务上下文；M1 使用独立私有 workspace 和记忆路径，公共任务不召回私信派生内容。私信任务禁止向群聊转发、委派或发布群组产物。宿主侧完整日志仍能由人类操作员导出。这提供智能体间可见范围，不是多个互不信任人类租户的权限系统。

M0–M2 的实际实现、迁移、批量产物、浏览器与预览边界见 [实施记录](m0-m2-implementation.md)。长期记忆的完整纠错/失效治理和自进化仍属于后续设计。

## 记忆与演进

各角色单独维护 JSONL。失败审查写入失败原因，审查通过或人类验收后写入模型提出的经验，明确标记 peer_approved、human_accepted、review_rejected 等结果。下一轮基于关键词重合度与时间检索；检索仅访问当前角色自己的记忆。经验标签表示谁认可了结果，不等于结论客观正确。

每次目标保存记忆文件前后 SHA256，便于追踪是否变化。建议评估冷启动与已有记忆两种条件：使用不同群组，固定任务顺序、模型和初始数据，对多次运行报告完成率和耗时分布；不要把同一任务重试的成功当成独立样本。当前尚未进行真实记忆增益实验。

## 隔离与工具网关

每次代码执行启动独立、非 root、只读根文件系统的 Docker 容器，只挂载当前角色 workspace。限制 512 MB 内存、1 CPU、128 个进程、最长 120 秒；移除 capabilities，禁止权限提升，不挂 Docker socket。默认无网络。文件网关限制相对路径、拒绝链接/隐藏目录/越界路径，文档仅允许纯文本，代码和 HTML 等可执行项目产物单独允许。

其他智能体目录、宿主 `.env`、日志及记忆不挂载。产物通过不可变 blob 显式发布，按 SHA256 验证后导入，避免共享工作目录。模型与检索密钥只留宿主进程；推送令牌仅传给人类批准后的临时推送容器。推送从复制的 Git 对象/引用构建干净裸仓库，不加载工作区 hooks/config。

这是课程级容器隔离，不声称达到抵御内核漏洞的多租户云安全级别。没有卷磁盘配额；输出捕获使用临时文件，返回截断到 32 KB。恶意无限写文件仍可能耗尽磁盘，应在可信课程测试环境运行并监测宿主磁盘。执行超时会尝试强制移除容器。

## 来源与时效性

Tavily 搜索与网页抓取结果分别标记为 search_snippet、fetched_text。来源记录 URL、检索时间、正文快照及内容哈希。网页脚本不会执行，脚本/样式文本不作为正文传给模型。抓取禁用代理、检查 DNS 公网地址、固定实际连接地址并保留 TLS 主机名验证；重定向逐次检查。

提示词要求引用一手来源、核对发布日期与事件时间、记录不确定性和相互矛盾的证据，并把网页视为数据而非命令。这是降低提示词注入的措施，不是对语义注入的形式化防御。要求未来时点的判断必须区分已观察事实与预测，不可伪造未来新闻。

## 指标与持久化

状态通过临时文件原子替换；CLI 为同一群组加操作系统文件锁，进程退出时由系统释放。旧版目录锁不会被自动忽略，需先确认旧进程结束。事件保留时间、任务、角色、动作及工具结果。单次模型连接故障保留队列供恢复；重新打开会话时恢复遗漏在队列之外的 running 任务；未捕获异常记录 fatal_error 并标记失败。当前不提供精确一次执行保证：若进程在外部推送成功、日志保存前崩溃，应先检查远端再决定是否重试。

总体完成率 = 人类验收通过且无致命错误的群聊目标数 / 已提交群聊目标数。子任务完成率 = 已通过审查的工作子任务 / 委派的工作子任务；不将审查任务计入分母。总耗时含真实人类等待；等待时间按所有请求区间并集计算，不能简单用总耗时减等待推算纯计算时间，因为其他任务可同时工作。模型用量仅汇总返回的 usage，未返回用量的失败请求不能视为免费。

## 成员接口与模型传输

B、C、D的最小结构契约位于`collab/contracts.py`，完整字段与语义见[编排集成契约](orchestration-contract.md)。现有`Tools`、`Store`和`Engine`分别满足工具、记忆与人类交互协议。

Windows Python 3.11+下，Python OpenSSL与当前HKGAI端点的握手可能停滞；`LLM_TRANSPORT=auto`在这种情况下使用系统curl的Schannel/TLS实现。认证凭据只通过子进程环境传递，不进入curl命令行或日志。该传输仍只访问课程允许的HKGAI/DeepSeek端点。
